      Import chats

      Paste a chat, or choose a file. Treechats reads chats copied with their speaker labels (You: / Claude:, User: / Assistant:, ChatGPT:), its own Markdown export, and the conversations.json file in a Claude or ChatGPT data export. ChatGPT exports keep their edited messages and regenerated replies as versions. Claude Code and Codex session logs (.jsonl) work too.
